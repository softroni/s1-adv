# S1-ADV 0.2.258

In short: Say sequences in the Lab

Tap Alt on the Sequences list and describe the steps, and Claude writes the sequence. To change one,
put the bar on it and say what's different, like "make it slower" or "make this one loop". It opens on
the same screen as a sequence from the chat, and nothing is saved until you press Enter.

Ask the Lab can now see every sequence's steps, so it can answer questions about them too. It still
can't start, stop or delete anything.

When a question has to leave part of the diary behind for lack of room, it now leaves the oldest hours
and keeps the newest. It used to be the other way round, and more sequences would have made that worse.

Writing a new sequence needs the bridge restarted. Changing a saved one also needs this update, because
the older firmware only told Claude their names.
