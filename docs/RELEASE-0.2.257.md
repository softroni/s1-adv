# S1-ADV 0.2.257

In short: Installing an update says so right away

Pressing Enter on the Firmware screen looked like nothing had happened until the device restarted a
few seconds later. The device had heard you, but its message never reached that screen. Now the bar
that offered the install turns green the moment you press and reads "Starting update...", the line
above it says "Please wait, it restarts by itself", and the header changes to STARTING.

Pressing Enter again no longer does anything. Each extra press used to start another update check,
so pressing again because nothing seemed to happen actually put the restart off.

The last screen before the restart stays up for a second and a half instead of half of one. It says
"restarting to install", and no longer shows 100% before anything has been installed.

With too little battery to install, the screen no longer offers Enter. It says the install needs more
charge, under the line that says how much.

"Do not power off" on the update progress screens ran through the panel's border. It now sits inside it.
