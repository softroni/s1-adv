# S1-ADV 0.2.245

In short: Rules can talk

Say or ask for a rule like "when someone walks in, say welcome back". The Cardputer speaks the phrase
once each time the rule starts firing.

The speech is made when you save the rule and kept on the SD card, so it plays with no network.
Sensors and rules wait while it speaks, and anything already on stays on. A phrase can be up to 40
letters, once in a rule, and it needs an SD card.

Your saved rules move to a new file format by themselves, and older ones still load.

**The bridge needs a restart for this.** Until then, it shows "Restart the bridge to use this."
