# S1-ADV 0.2.225

The device now tells you which stage a request is in, on screen and by ear. Home shows
SENDING, THINKING, LOADING and SPEAK.

Each stage has its own soft sound, in place of the old sharp beeps: two rising notes when a
typed message goes out, two low taps when the assistant takes it, and two falling notes when
the reply is ready. A voice message makes no sound while sending, because the speaker is off
during the upload, and no sound marks speaking, because you can hear it.

Searching and writing code still show as THINKING. The bridge doesn't report them yet, so the
device can't tell them apart.
