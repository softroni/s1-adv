# S1-ADV 0.2.212

The Pulse screen now moves only while the assistant is thinking or working: waiting for a
reply, loading voice, or running a build or task. It stays still the rest of the time,
including while it listens or speaks.

The clock, the recording timer and the playback progress bar keep updating. The mic level
meter and the playback spectrum no longer appear on this screen unless the assistant is
also working. The Realtime screen and voice player are unchanged.
