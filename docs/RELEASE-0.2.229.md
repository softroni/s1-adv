# S1-ADV 0.2.229

**Weather on Pulse.** When nothing is happening, the orb gives way to the date, temperature,
conditions, high and low, chance of rain and place. It updates after the device starts and then
every 30 minutes. Set your ZIP code under Settings, Device, Weather ZIP. The default is 10001.
This needs the bridge restarted on the new code.

**Tap Alt to talk.** Tap Alt once to start listening and again to send, so you no longer have to
hold G0. It works on Pulse, AI Chat and the other assistant screens, and it stops a reply that's
playing. AI Chat shows a red Listening bar with the time. G0, Ctrl+V and double Ctrl still work.

**The menu remembers.** Tab opens on the app you last used, instead of going back to Pulse, and
this survives a restart.
