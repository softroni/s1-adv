# S1-ADV 0.2.222

The device now remembers Wi-Fi networks. Once a network connects, it's saved to the SD card, and
it appears at the top of Settings, then Wi-Fi. Press Enter on a saved network to switch to it
with no password. Press F, then Enter, to forget one and delete its password.

Saved networks stay through firmware installs. The file is encrypted with a key tied to this
Cardputer's chip, so a lost card doesn't give up your passwords. That also means the file can't
be read on a computer or moved to another Cardputer.

If a saved network's password has changed, the device asks for the new one and keeps the rest of
the list. The setup portal is unchanged. A network set there is saved once it connects.
