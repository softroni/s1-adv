# S1-ADV 0.2.233

**Bigger text on eight more screens.** Files, NES Games, Notes, Wi-Fi, Firmware, Internet Radio,
Alarm and VLC Remote now use the same big rows and type as the app menu. The lists show five rows
and scroll. Key hints stay small at the bottom or top, because they only fit that way.

**Letters jump to menu groups.** In the app menu, press A for AI Agent, M for Media, F for Focus,
T for Tools, G for Games, R for Arcade, S for Settings, Y for System or L for Lab. The selected tab
underlines its letter.

**The menu's keys changed.** The letters took over from W, A, S, D and H, J, K, L, so move with the
arrow keys. Tab, Enter, the number keys and Ctrl+number work as before.
