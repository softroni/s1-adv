# S1-ADV 0.2.230

**Colour weather icons.** Sun, moon, clouds, rain, snow, fog and storms now have their own colours
on the Pulse screen.

**Set a city instead of a ZIP code.** Weather now uses a city name, so Pulse shows the place you
expect. Find it under Settings, Device, Weather city. The default is Salem, MA. Include the
state, because many towns share a name. This needs the bridge restarted on the new code.
