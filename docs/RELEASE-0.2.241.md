# S1-ADV 0.2.241

In short: Say a rule with Alt

Say a rule now uses the chat's recorder. Tap Alt to listen and tap it again to send, and Esc cancels.

Before, Enter was the only way to start, and once it was listening neither Enter nor Alt would stop
it. Esc left the screen with the microphone still on, and "No rule came back" appeared while Claude
was still writing the rule.

The rule now comes straight back in a few seconds, and it no longer goes through the chat. If Claude
can't make a rule, the screen shows what it needs and what it heard.

The recorder is also ready for other apps: any screen can get the words you said, or Claude's answer,
with a line of code. See `docs/VOICE-TOOLS.md`.

**The bridge needs a restart for this.** Until then, Say a rule shows "Restart the bridge to use
this."
