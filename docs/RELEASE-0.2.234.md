# S1-ADV 0.2.234

The Lab now works the way it was asked to.

Rules are built and changed one question at a time. Enter on a saved rule walks the same steps with
your answers already picked, and the steps now also cover adding a second or third line, any or all,
how long a rule keeps going, and its name. The all-in-one rule card is gone.

Playing shows each rule as a picture with dots moving from what set it off to what it drives. Left
and right change rule, and a row of dots shows every rule at once. The board view is gone.

**Say a rule** turns a spoken request into a rule. Claude's answer is shown before anything happens,
and Enter saves it. This needs the bridge restarted, because the bridge is what teaches Claude the
format. Until then it says no rule came back.

**Recipes** add one of ten ready-made rules for these parts.

**Practice** tries a rule from the keyboard with nothing plugged in. Press T on the Playing screen.

Rules can now drive the smartLamp, and turn a TCL or Daikin air conditioner on and off by infrared.
These are left alone until a rule asks, and only an "on" that a rule sent is undone.

Rules saved in 0.2.232 still load. All of this has only run against simulated units so far.
