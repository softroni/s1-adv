# S1-ADV 0.2.227

The app menu is much easier to read. It now fills the screen and shows five rows at a time, with
text almost twice as tall and a new icon for every app. The selected row is a solid bar in the
group's colour.

All eight groups stay visible as tabs across the top, and the selected tab shows the group's
name. Tools is now yellow, because it looked identical to Focus.

**The keys changed.** Up and down pick a row, left and right switch group. W/S and A/D do the
same. Enter, Tab, 1-8 and Ctrl+1-8 work as before, and each row shows the number that Ctrl
opens it with.
