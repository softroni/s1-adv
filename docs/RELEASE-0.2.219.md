# S1-ADV 0.2.219

Hot Air Balloon sounds gentler. Collecting a star now plays a soft two-note chime that fades
away, in place of the sharp beep. Hearts, new levels and bumps have matching soft chimes.

A quiet music box plays a slow, original waltz in the background while the game is open. It
pauses behind the menu and stops while the assistant is using the mic or speaker.
